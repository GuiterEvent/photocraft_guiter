這是PhotoCraft在分支點的右鍵單擊行為的源程式碼清單，捕獲於 2026 年 10 月 6 日。它將選單與其他輔助按鈕手勢區分開來。此 PR 新增的初始選擇、路徑行和文件標籤選單是單獨呼叫的。在聲明精確奇偶校驗之前，應對照已識別的Photoshop版本和平台檢查Photoshop比較；目前的圖層選單明確針對Photoshop2026 順序。

## Canvas：每一個工具

共用規則是 **Command/Ctrl + 右鍵點選*不透明文件像素 → 此時可見圖層的最上面第一個清單；選擇一行調度`layer.select`。移動工具也可以透過右鍵單擊來獲得該選單。該清單來自`layer.pickAt`，並且在完全透明的像素上被省略。在其餘工具上，普通右鍵取決於下面的工具組。畫布行為位於`canvas.rs`、`paint_mouse.rs`、`layer_pick_ui.rs`和`brush_resize.rs`中。

|工具|今天簡單的右鍵|其他輔助手勢 |平價工作|
|---|---|---|---|
|移動|指針下層清單（`layer.pickAt`、`layer.select`）| Command/Ctrl 給予相同的清單 |驗證Photoshop修改器和自動選擇行為；測試重疊、遮罩、群組、變換像素、空白區域。 |
|筆刷、鉛筆、橡皮擦、背景橡皮擦 |筆刷預設選擇器（尺寸、硬度、預設）| Alt/Option + 右鍵拖曳透過`tools.setBrush`變更尺寸/硬度；筆刷/橡皮擦可以透過`tools.rightClickWithPaintingTools=erase`拖曳擦除」上下文是否應公開筆刷預設、橡皮擦設定或控制特定工具的控制項。保持擦除首選項和修改器優先權的確定性。 |
|污點修復、修復、複製圖章、歷史筆刷、模糊、銳利化、塗抹、減淡、加深、海綿|筆刷預設選擇器 | Alt/Option + 右鍵拖曳更改大小/硬度 |比較每個工具的Photoshop選擇器和來源/修飾選項；使用現有的筆刷命令路徑。 |
|快速選擇 |筆刷預設選擇器 | Alt/Option + 右鍵拖曳更改大小/硬度 |檢查選擇工具筆刷選項以及模式控制項是否屬於選取器。 |
|矩形/橢圓選框、套索、多邊形套索、磁性套索、魔棒、物件選擇 |選擇上下文選單：帶有選取的完整Photoshop列表，選取全部/重新選取/色彩範圍/載入選擇，不含（`canvas_tool_menu.rs`，`docs/context-menu-parity.md`中的行）| PH/Z3119CtZ捕獲確認無選擇變體。 |
|裁剪、切片、切片選擇 |沒有簡單的次要動作| Command/Ctrl 開啟圖層清單 |分別定義裁剪/拉直提交和取消、方面/預設、切片選擇/編輯行為。 |
|吸管、尺、筆記、計數 |沒有簡單的次要動作| Command/Ctrl 開啟圖層清單 |檢查特定於工具的取樣、測量、註解和計數選單。 |
|漸層，油漆桶|沒有簡單的次要動作| Command/Ctrl 開啟圖層清單 |如果Photoshop的上下文 UI 提供了漸層預設和填滿設置，則透過命令公開它們；避免右鍵單擊時繪畫。 |
|類型 |沒有簡單的次要動作| Command/Ctrl 開啟圖層清單 |測試文字編輯與非編輯上下文、拼字、類型選項和選擇行為。 |
|筆，路徑選擇|沒有簡單的次要動作| Command/Ctrl 開啟圖層清單 |高優先權路徑點上下文契約：新增/刪除/轉換點、關閉路徑、進行選擇、填入/筆畫路徑、適用時的路徑操作。 |
|矩形、橢圓形、三角形、多邊形、直線、自訂形狀 |沒有簡單的次要動作| Command/Ctrl 開啟圖層清單 |定義形狀與路徑上下文、點編輯、填滿/筆畫和變換條目。 |

畫布不變式：二次點選不得意外開始繪畫筆畫、提交裁切或編輯文件；每個變異選單操作都會調度一個指令。退出/外部點選可關閉彈出視窗。現有`ui.pointer`支援輔助按鈕； UI 測試應該使用本機手勢和控制驅動手勢。

## 實施合約

1. 按版本、作業系統、表面、工具和狀態（空/選擇/路徑/文字編輯/多層）記錄Photoshop參考矩陣。擷取準確的專案標籤、順序、分隔符號、子選單、停用條件和修飾符變體。標記觀察與推理。
2. 使用謂詞測試將選單描述符編碼為資料。透過現有或新的引擎命令 ID 路由文件編輯；僅查看操作可以保留在 UI 中。畫布上的選單必須從命中測試中接收文件座標和相關目標，因此操作會對點擊的內容進行操作，而不是默默地對不相關的活動物件進行操作。
3. 優先考慮共享畫布選單，然後是高價值的特定於工具的互動（路徑、選擇、類型、裁剪/縮放），然後是面板和選項卡間隙。重用命令合約已存在的層/色版實現。保留現有的移動/圖層選取、筆刷選取器、擦除首選項、Alt/Option 筆刷調整大小和工具列彈出手勢。
4. 測試每個描述符的專案順序和啟用情況，使用預期參數、空/無效狀態、修飾符和操作結果進行調度。新增右鍵開啟、目標選擇、Escape/外部解除以及避免意外編輯的 UI 手勢測試。驗證本機和 Web 建置。
5. 從正在執行的應用程式中捕獲代表性工具組和麵板狀態的螢幕截圖，並使用測試夾具文件而不是個人照片。螢幕截圖證明了可見的選單組成；命令測試證明其行為。
