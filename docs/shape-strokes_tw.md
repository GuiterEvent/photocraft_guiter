# 形狀筆畫選項

更新於 2026 年 10 月 11 日：直接編輯、緊湊佈局和可點擊的顏色/樣式控制。

PhotoCraft的形狀工具選項列在現有寬度旁邊有一個筆畫選項按鈕
和顏色控制。它為新的矩形、橢圓形、三角形、多邊形、直線設定預設值
和自訂形狀圖層。形狀模式下的筆使用相同的預設樣式；開放筆形狀保留
他們現有的前景色和最小 1 像素寬度。若要編輯現有形狀，
使用屬性 → 外觀 → 筆畫選項。

填滿和筆畫樣本可點選並開啟現有的緊湊型顏色選擇器。選擇
顏色保留其 alpha；無顏色會去除相應的油漆。工具列填滿用途
前景色和筆畫像以前一樣使用背景色。選擇中風
當不存在筆劃時，顏色或樣式故意啟用 3 px 筆畫。樣式按鈕
無需任何筆劃即可保持可用，但單獨打開或關閉它並不能啟用筆劃。
屬性編輯選定的形狀；選項列繼續為新形狀設定預設值。

編輯器提供實線、虛線（4 個寬度打開，2 個關閉）、點線（帶有圓形的零長度虛線）
大寫字母，每 2 個寬度間隔），以及自訂重複破折號/間隙序列。短劃線長度和
偏移量是筆畫寬度的倍數；寬度本身以文件像素為單位。奇數長度
導入的序列重複兩次，遵循現有的渲染器約定。最多 16 個
可以使用新增對/刪除對來編輯破折號/間隙對。零長度破折號以以下方式繪製點
圓帽和方帽；對接帽在零長度破折號處不繪製任何內容。
每個預設的整行（包括其行樣本）都是一個可點擊的目標，帶有可見的
選定的狀態和可存取的標籤。

帽子有平頭/平頭、圓形和方形。它們影響開放端點和單一虛線
段。封閉的實體形狀沒有端點，因此它們的帽控制被停用。角球
是斜接、圓形或斜角；斜接限制是一個比率，1–500（現有預設值仍為 100）。
超過限制的尖銳斜接會變成斜角。橢圓沒有尖角，所以它的角
控制被禁用。線條工具保留其現有的實心條幾何形狀：筆畫跟隨
酒吧的封閉輪廓。使用開放筆形狀作為帶有端點帽的中心線。

內部/中心/外部對齊適用於子路徑全部閉合的路徑。裡面
和外部在形狀的填滿區域上夾出雙倍寬度的筆畫，並尊重現有的
填滿規則和元件操作。開放和混合開放/封閉路徑使用中心；他們的
對齊控制被禁用。虛線長度繼續使用指定的寬度，包括
對於內部和外部。不透明度與寬度和油漆無關。

筆畫選項立即套用有效的更改，並且沒有“應用”或“取消”按鈕。
Properties透過`shape.edit`傳送變化；一次連續的數位拖曳就是一次撤銷步驟。
退出或點選外部可關閉彈出視窗並保留已套用的變更。開幕或
在不更改值的情況下關閉它不會建立任何歷史記錄條目。無效的待處理數值
不要替換最後一個有效的樣式。子下拉式選單可以開啟並選擇一個選項，而無需
取消筆畫選項；逃避在父母之前關閉了孩子。彈出視窗適合它
僅在可用高度需要時才顯示內容和捲動。

緊湊的線條和矩形預覽使用真實的向量渲染器。工具預設更改
不要編輯該文件。形狀拖曳預覽使用向量渲染器和快取螢幕
代理的最長軸上限為 2048 像素；就像之前的拖曳疊加一樣，它們的顏色
繞過監視器設定檔轉換。提交的形狀，包括即時屬性編輯、使用
普通的顏色管理合成器。

需有限值：寬度 0–1,000,000 px，不透明度 0–100%，虛線/間隙長度
0–10,000 個寬度，偏移 ±1,000,000 個寬度，最多 32 個長度，並且總共有一個非空圖案
至少 0.01 寬度。互動式指令拒絕超過 ±1,000,000 像素的幾何圖形，
超過 4096 節/子路徑、超過 100,000 個曲面細分點或超過的衝刺工作負載
100,000 步。文件提供的無效/密集模式在渲染期間受到限制。有
此變更中沒有自訂已儲存的預設庫。樣式預設使用現有的 serde UI 狀態，
但應用程式不會在重新啟動時保存和恢復這些預設值。

所有欄位均已存在於`ShapeStroke`和本機清單/轉換中。舊`.pcraft`
文件保留其 serde 預設值；保存保留所有樣式欄位。 PSD 匯入/匯出地圖
透過`vstk`的相同欄位（線寬、虛線設定/偏移、上限、連接、對齊、斜接限制、
不透明度和油漆）；現有的未知層塊和原始相容向量記錄
仍然由現有的 I/O 路徑處理。筆畫疊印，非正常 PSD 向量筆畫
混合模式、角部擬合破折號最佳化以及Photoshop儲存的筆觸預設庫
沒有實施。Photoshop創作的預言機在此沒有建立精確的筆畫 UI 奇偶校驗。

自動化：`shape.create`、`shape.edit`和`shape.info`公開文件筆畫。的
控制色版也支援`ui.set {shapeStroke: {width,align,cap,join,miterLimit,
dashes、dashOffset、opacity}}` 用於工具預設值、合併部分欄位； null 將寬度設為
零。使用`tools.setColors`設定工具顏色。`ui.inspect`報告`toolOptions.shape_stroke`，
`toolOptions.stroke_width`和瞬態`strokeEditor`。鍵盤焦點，標準數
欄位、顏色選擇器和組合方塊仍然是本機egui控制項。

## 上游和公共參考

- [PR #2218](https://github.com/storytold/photocraft/pull/2218) 引入了這些控件
  分階段進行預覽。上面的直接編輯互動取代了「應用程式/取消」工作流程。
- [問題 #2496](https://github.com/storytold/photocraft/issues/2496) 追蹤更廣泛的形狀工具
  奇偶校驗，包括從選項列進行選定形狀編輯和其他填滿類型；
  這些仍然是單獨的工作。
- [問題 #1053](https://github.com/storytold/photocraft/issues/1053) 記錄了缺少的內容
  衝程控制和現有引擎/模型支援。漸層填滿 UI 仍然是單獨的工作。
- [問題#1931](https://github.com/storytold/photocraft/issues/1931) 需要銳利的筆畫選項。
- [PR #233](https://github.com/storytold/photocraft/pull/233),
  [#397](https://github.com/storytold/photocraft/pull/397)，以及
  [#1495](https://github.com/storytold/photocraft/pull/1495) 已解決筆畫合成問題，
  髮際線和深度保留；他們的實現被重複使用。
- [PR #2031](https://github.com/storytold/photocraft/pull/2031) 提供點擊建立
  對話方塊。對話方塊和拖曳創建都使用其共享的`create_shape`幫助程序，該幫助程序接收
  完整行程預設值。手勢回歸檢查兩條路徑及其撤銷步驟。
- Adob​​e 的 [Photoshop形狀填滿/筆畫指南](https://helpx.adobe.com/photoshop/desktop/draw-shapes-paths/create-shapes/fill-and-stroke-shapes.html)
  描述工具選項和屬性入口點及其
  [蓋子/連接參考](https://helpx.adobe.com/ca/illustrator/desktop/paint-and-fill/apply-and-edit-strokes/change-the-caps-or-joins-of-a-line.html)
  定義端點和轉角行為以及 1-500 斜接範圍。破折號單元重複使用
PhotoCraft現有記錄的`ShapeStroke`/`vstk`約定。
