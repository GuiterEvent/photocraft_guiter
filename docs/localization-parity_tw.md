# 在地化平價

> **最後審核：** 2026-10-12 · **最後更新：** 2026-10-13 · **更改：** 次要（西班牙語動態標籤；之前次要：塞爾維亞目錄） · **目標：** Adob​​ePhotoshop2026

PhotoCraft的 UI 的每種語言狀態。目錄的工作原理以及如何添加目錄：
[`localization.md`](localization.md)。語言註釋：[韓文](localization-ko.md)、[西班牙文](localization-es.md)、
[簡體中文](localization-zh-hans.md)、[義大利文](localization-it.md)。

**如何測量。 **`cargo xtask i18n-coverage`(`xtask/src/i18n_coverage.rs`) 定義金鑰
Universe：`ui-egui`中的`tl!("…")`文字和`trn(`複數（排除測試），選單目錄
標籤和路徑段、`menus.rs`UI 指令以及引擎`CommandSpec`標籤和選單路徑：
**2026 年 10 月 10 日有 1,608 個英文鍵**。每個目錄（`crates/ui-egui/src/i18n/<code>.tsv`）
透過複製 xtask 的來源指令碼（無建置）對該 Universe 進行檢查。目錄持有
比宇宙更多的行，因為它們也轉換動態`tl!(expr)`字串（~159 個呼叫
該工具無法枚舉的站點）。 **任何地方均未涵蓋：** 引擎錯誤和狀態訊息以及
過濾器參數幫助，各語言都有英文；所以沒有語言是`full`。

**Photoshop2026** 提供 cs、da、de、en、es、fi、fr（和 fr-CA）、hu、it 的 UI 語言包
ja、ko、nb、nl、pl、pt-BR、ru、sk、sv、tr、uk、zh-Hans、zh-Hant（24 個`.lproj`標記；一包為
根據 Creative Cloud 安裝進行安裝，此處為`en_US`）。它沒有印地語、阿拉伯語、印尼語或
越南語使用者介面；阿拉伯語和希伯來語使用者可以透過 World-Ready 獲得英語“中東”版本
Composer，其文字引擎可以處理 RTL、梵文和印度文指令碼。

**摘要。 ** 12 種關鍵語言中的 7 種在 100% 測量的按鍵上（狀態`partial`，因為
引擎訊息），缺席 3 種語言（印地語、阿拉伯語、越南語），以及其他 8 種語言。加權依據
揚聲器，約 55% 準備就緒。剩餘時間：80–140 小時，加上母語人士複習（僅記錄義大利語、
2026-10-12).

另外 8 個，每個位於 1,608 / 1,608 個測量鍵，狀態為`partial`，原因相同：傳統
中國`zh-hant`（2,329 行）、俄羅斯`ru`（2,544）、烏克蘭`uk`（3,375）、捷克`cs`（3,522）、

波蘭語`pl`(3,366)、希臘文`el`(3,481)、荷蘭語`nl`(3,568)、義大利語`it`(4,164；還有每個動態標籤
其他目錄翻譯；由母語人士審閱，[註釋](localization-it.md))。土耳其語`tr`
（3,731 行）也涵蓋了每個測量的鍵。塞爾維亞語`sr`（4,022 行，拉丁文字，Ekavian，2026 年 10 月 12 日新增）涵蓋了所有
測量的鍵和其他目錄動態標籤的並集；它的一個/幾個/許多複數重複使用
俄羅斯的統治。

捷克 UI 後續（2026-10-11）：狀態和通知包裝器、硬體標籤、刷子和
轉換輔助使用名稱、點陣化提示、設定檔不符訊息和預設
計數現在在其渲染/分配站點進行轉換。導航器的縮放等級使用上下文
(`Zvětšení`)，而刀具仍為`Lupa`。引擎錯誤，設定檔/文件/文件名稱保留
逐字記錄；複製的系統資訊和控制 API 診斷在螢幕上保持英語狀態
標籤翻譯。導入警告計數在捷克語中使用括號。新動態模板落地
在沒有條目的目錄中返回英文。這是額外的 UI 保險，而不是聲稱
引擎本地化或原生審核已完成。

## 跨語言差距

- 各種語言的引擎錯誤、狀態和參數幫助訊息均為英語。
- 從右到左的 UI 佈局是部分的 (2026-10-10)：阿拉伯語、希伯來語、波斯語的 shell 鏡像，
  烏爾都語和其他從右到左的程式碼 (`direction.rs`)，但面板內部、對話方塊、選單列、
  子選單和文件標籤保持從左到右。 UI 標籤也缺少阿拉伯後備字體，並且
egui0.36 連接單字內的字母，但將一行單字從左到右排序（無雙向）。
- Web 建置：無瀏覽器區域設定偵測，無 CJK Web 字型。
- 當 UI 不是英文時，WebAssembly外掛程式會從濾鏡中消失 › 外掛程式 (#2540)。
- 使用者找不到語言選項 (#2532)：它位於首選項 › 介面中。
