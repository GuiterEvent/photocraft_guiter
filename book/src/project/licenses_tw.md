# 許可證

PhotoCraft原始碼由 MIT 或 Apache-2.0 雙重許可，由使用者選擇。權威術語是儲存庫文件：

- [`LICENSE-MIT`](https://github.com/storytold/photocraft/blob/main/LICENSE-MIT)
- [`LICENSE-APACHE`](https://github.com/storytold/photocraft/blob/main/LICENSE-APACHE)
- [`NOTICE`](https://github.com/storytold/photocraft/blob/main/NOTICE)
- [`ATTRIBUTION.md`](https://github.com/storytold/photocraft/blob/main/ATTRIBUTION.md)

捆綁的第三方資產保留自己的許可證和歸屬要求。`docs/brand/`中的ArtCraft名稱、字標和標誌受 [`docs/brand/LICENSE-brand.txt`](https://github.com/storytold/photocraft/blob/main/docs/brand/LICENSE-brand.txt) 約束，且不受原始碼授權的約束。

此頁面總結了儲存庫位置，並不會改變任何所有權或許可條款。
