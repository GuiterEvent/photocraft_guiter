#SVG

SVG 將作為形狀圖層文件打開，並將（文件 > 嵌入位置/連結位置）放置為向量智慧物件。兩者都經過`photocraft-io`的`svg`模組；沒有 SVG 導出。

## 開幕

`usvg`解析檔案（它與 UI 圖示經過的套件相同）：解析 CSS、`use`、單位、嵌套變換和`viewBox`，並使用捆綁的製程字體以及桌面上的系統字體將文字塑造成輪廓。生成的樹依繪製順序變成圖層：

| SVG |層|
|---|---|
|`path`、`rect`、`circle`、`ellipse`、`line`、`polyline`、`polygon`|形狀圖層：立方貝塞爾結，其中包含元素的變換、蓋、折、折、不面飾）。 |
|`g`與`id`、不透明度或混合模式 |具有不透明度和混合模式的圖層群組。僅攜帶變換的組不是層。 |
|`text`|一組以文字命名的輪廓形狀。 |
|線性和徑向漸層塗料|圖層自己的漸層填滿帶有停止點和方向；不保留確切的梯度幾何形狀（警告如此說明）。 |
|`clip-path`、`mask`、`filter`、圖案塗料、`image`|由`resvg`點陣化為元素邊界框上的像素圖層，因此圖片看起來正確，而這些部分名稱類型編輯為形狀（警告每種名稱不可類型）。 |

畫布是 CSS px 中的繪圖大小（來自`width`/`height`，否則為`viewBox`），RGB 8 位，透明，不繪製任何內容。一邊大於 16 384 像素的繪圖會按比例縮小以適應。超過 2000 個元素後，繪圖將作為單一像素圖層而不是數千個形狀開啟。格式錯誤的 SVG 是一個錯誤，而不是恐慌；`.svgz`被其擴展名接受，並且當擴展名丟失時，純 SVG 也能被內容識別。

## 排名

放置的 SVG 將其位元組保留為智慧型物件的來源。每當渲染智慧型物件時（在放置時、自由變換後、智慧濾鏡更改時），繪圖都會按放置的比例進行柵格化，然後定位，因此它在 1000% 處保持銳利，而重新採樣的柵格會變得模糊。編輯內容開啟來源作為上面的形狀圖層文件；與任何智慧型物件一樣，將其儲存回來會儲存編輯後的文件。

限制：單次渲染上限為2400萬像素；扭曲的智慧型物件和堆疊根據繪圖自身的大小進行渲染。
