# 模糊遮罩效能

大半徑原生Unsharp Mask使用與原始可分離的FFT卷積
離散高斯係數和現有的`rustfft`相依性性。一個串流媒體
可分離路徑保留原始的抽頭順序以進行精確處理。

FFT 適用於半徑 64–1000 且至少有 65,536 個輸出像素（非零）
金額和零或負臨界值。正臨界值、不穩定樣本、
不受支撐的幾何體和不充分的划痕使用精確的路徑。WebAssembly
保留精確的處理。 Alpha、選擇、邊緣和取消都保留。
智慧銳利化、高通和共享模糊數學保持不變。

FFT 改變求和順序並允許較小的捨入差異。測得的
最大為 1 個 8 位元儲存級別，大約為 1 個 16 位元級別，以及 8.762e-6
適用於 HDR 燈具。精確路徑比較是位元組相同的。變換軸
上限為 32,768； FFT 暫存分組的預算為 1 GiB，不包括文件
瓷磚。這不是整個處理程序的記憶體限制。

之前/之後的數字、基準方法、數值公差和預覽
測量限值記錄在 [PR #2987](https://github.com/storytold/photocraft/pull/2987) 中。
比較使用合成影像並測量 CPU 計算，而不是滑桿
事件到螢幕的延遲。沒有公佈的效能預算或渲染同等性
地板透過這些測量而升高。
