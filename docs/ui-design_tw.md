視窗 → 主題和 macOSPhotoCraft→ 外觀也提供與系統同步。它的複選標記遵循已儲存的自動模式而不是顯示的調色板；選擇手動主題即選擇其固定外觀模式。

工具列的前景色和背景色片遵循`Tokens::round_chips`標誌。 Pro 和 Classic 將其保留，並在其上方繪製Photoshop的重疊方塊，並在其上方使用預設顏色和切換顏色。 Studio、Studio Light、Solarized Dark、Adwaita、Adwaita Dark、Breeze Light、Breeze Dark、Soft Dark 和 Soft Light（Studio 佈局主題）將其打開，並繪製大的圓形色塊，其正下方有一個彎曲的“切換顏色”箭頭，其頭部接觸色塊：垂直堆疊在一個工具欄中，預設設置在一個頂部工具欄中，預設顏色位於兩個頂部區域。另一個非專業主題可以透過設定標誌來選擇加入。

## 規則

- **顏色和半徑來自標記。 ** 使用`Tokens::get(ctx)`讀取它們；切勿在小部件中硬編碼顏色。
- **`widgets.rs`中的共享小工具：**`card`（面板組；Pro 呈現Photoshop選項卡條）、`value_field`、`slider`/`slider_row`、`toggle`ZXZ、Z`primary_button`/`secondary_button`、`dropdown`（附 V 型圖示）、`hairline`/`vline`、`elided_label`。
- **標籤永遠不會溢出其行。 ** 預設換行。在固定寬度控制項旁邊，或任何行無法重排的地方，請使用`widgets::elided_label(ui, text, max_w)`：較長的翻譯會隨著`…`縮小，並在懸停時顯示完整字串，而不是越過其鄰居 (#3580)。 *多餘的*標題可能會被放置在一個狹窄的停靠欄上，其中它的控制項已經帶有含義（例如，圖層鎖定圖示）；一個*必要的*被省略了。這反映了Photoshop：具有省略和工具提示的固定佈局，而不是按區域設定回流。
- **圖示：**`assets/icons`中的 Lucide SVG（ISC 許可證），透過`icon_data.rs`嵌入。新增圖示時重新產生該檔案。
- **字體：** Inter (UI) 和 JetBrains Mono（數字），都是 OFL。命名系列`medium`和`semibold`可透過`theme::medium()`和`theme::semibold()`取得。
- **Photoshop版面語法（專業版）：**
  - 必需品碼頭順序：顏色 |樣本，然後屬性 |調整，然後圖層|頻道 |路徑（圖層填滿剩餘高度）。
  - 選項列標籤以冒號結尾（「大小：」）。
  - 文件標籤顯示為「name @ 12.5% (RGB/8)」。
  - 工具列工具組有一個角三角形。
- **使用`ui.screenshot`在多種視窗大小和每個主題中驗證每個視覺變化**。

## 交互模型（匹配PhotoshopCC）

|特色 |模組|行為 |
|---|---|---|
|類型工具|`type_tool.rs`|點選：點選取佔位符「Lorem Ipsum」的文字。拖曳：段落框。內嵌插入符號和從文字引擎佈局中繪製的選擇。 ⌥/⌘ 單字和行導航，↩ 換行符，⌘↩ 或 Esc 提交，在提交之外點擊。每個會話一個歷史記錄步驟 (`coalesce`)。新圖層以其文字命名；一個空的被刪除。 |
|自由變換 |`transform_tool.rs`| ⌘T。角和邊按比例縮放（⇧釋放它們：一邊然後拉伸一個軸）； ⌥ 圍繞參考點縮放； ⌘-角扭曲；向外拖動旋轉（⇧ 捕捉到 15°）；拖動內部動作。預覽 = 沒有移動像素的文件 + 帶有紋理的 24×24 網格。 ↩ 或透過`edit.transform {rect, quad}`雙擊提交。 |
|快速圖層選擇|`quick_pick.rs`| macOS：使用任意工具按住 ⌘⌥⌃ 點擊即可選擇指針下方有像素的最上面的可見圖層 (`layer.pickAt`)，無需切換工具；拖曳和釋放被吞沒。 Windows/Linux 沒有與 ⌃⌥ 筆刷調整大小不同的第三個修飾符，因此該手勢是無操作的（使用移動工具的自動選擇）。失敗的選擇是狀態列錯誤。 |
|圖層行|`panels.rs`|雙擊：在名稱上重新命名到位；在背景上使其成為普通圖層；在調整或填滿縮圖上開啟其屬性；在智慧型物件縮圖上開啟其內容（編輯內容）；該行的其他任何位置都會開啟圖層樣式。 |
|圖層遮罩 |`panels.rs`|點選遮罩縮圖將目標遮罩（角括號框；標籤顯示「圖層，圖層遮罩/8」）。筆刷、橡皮擦（繪製背景顏色）、漸層、桶並移動選定的像素（⌘拖動，`select.float`；孔採用背景顏色），然後發送`"target": "mask"`。調整和填滿圖層自動瞄準其遮罩。 |
|頻道選擇|`channels_panel.rs`|將頻道載入為頁尾中的選擇，跟隨已反白的頻道行。當活動圖層遮罩以繪畫為目標而底層色版視圖保持複合時，它會加載該圖層遮罩；否則，它會加載選定的複合、顏色、Alpha 或向量遮罩色版。 |
|路徑縮圖 |`vector_ui.rs`|按住 Ctrl/Cmd 鍵點選工作路徑、儲存路徑或圖層路徑的縮圖，將其載入為選取範圍； Shift 加法、Alt 減法、Shift+Alt 相交。按一下行名稱僅選擇路徑。 |
|水平/曲線|`tone.rs`|調整*下方*影像的分佈圖。曲線：點選新增點，拖出刪除。每一項變更都是合併的`layer.setAdjustment`，因此一次拖曳 = 一次撤銷步驟，並且畫佈在 GPU 上以全解析度更新。 |
|形狀筆畫選項|`shape_stroke_ui.rs`、`vector_ui.rs`|直接編輯：有效的變更會立即套用，在屬性中每個撤銷步驟只需拖曳一次數字即可。 Escape/外部點擊關閉彈出視窗並保留變更；子下拉選單可使父選單保持開啟。選項列設定新形狀預設值；屬性編輯選定的形狀。 |

形狀筆畫選項（更新於 2026 年 10 月 11 日）根據其內容調整大小，並僅在必要時捲動。
它沒有應用/取消頁腳。實線、虛線和點線是帶有線條的完整可點擊行
樣品和可見的選擇；單獨打開編輯器永遠不會改變形狀。無效待處理
數字輸入保留最後一個有效樣式。填滿和筆畫使用可點擊的樣本
以及現有的緊湊型顏色選擇器，保留 alpha 並提供無顏色。風格
未設定筆劃時按鈕仍可使用；刻意選擇筆畫顏色或
style 啟用 3 px 筆畫。顏色、邊框和選擇處理來自主題標記。
這些工具預設為 serde 狀態，但不會在應用程式重新啟動後恢復。參見
[`shape-strokes.md`](shape-strokes.md) 用於幾何、色彩管理和餘輝限制。

編輯類型時，按住 Ctrl (Windows/Linux) 或 Command (macOS) 進行定向變換
框架。向內拖曳可移動，角落可縮放（Shift 保持比例；Alt/Option 縮放
參考點）、中間手柄進行傾斜，或在框架外部進行旋轉（Shift 捕捉
至 15°）。拖曳參考點以移動旋轉中心。這些類型的手勢遵循
[Adobe 的型別指南](https://helpx.adobe.com/photoshop/using/creating-type.html)，獨立
「自由變換」首選項的屬性：Ctrl/Cmd 絕對不會扭曲文字角落。

如果沒有 Ctrl/Cmd，段落句柄將調整容器大小並重排其文字。臨時的
轉換保持其邏輯維度和所有字元/段落樣式。拖曳開始於
Ctrl/Cmd 擁有指針，直到按鈕釋放，即使先釋放修飾鍵也是如此。其
預覽不會改變文件；釋放應用一個合併的`type.edit`，然後鍵入
繼續在同一層。拖曳期間退出會取消該預覽；焦點喪失或改變
至其源頭亦棄之。按住修改器、移動參考點或返回
指向其開頭的指標不會建立歷史記錄條目。鍵入時按 Ctrl/Cmd+T 仍會切換
人物面板。

如果字體缺少符號（例如 ∠ ↦ ▔），請使用畫家繪製或使用 Lucide 圖示；從不出貨
缺少字形框。使用離屏快照工具 (`docs/development.md`) 檢查每個新面板。

## 標題列

應用程式的頂部欄 (`panels::title_bar`) 從品牌標記（應用程式圖示`brand.rs`）開始，然後是選單、文件標題和工作區控件，例如Photoshop的 Ps 磁貼和選單行。

- **Windows 和 Linux：** 視窗沒有作業系統裝飾，因此只有一個欄，而不是兩個堆疊的欄位。頂部欄是標題列 (`titlebar.rs`)：最小化、最大化/恢復和關閉（懸停時為紅色，`caption_close`標記）與窗口的右上角齊平，菜單和控制之間的自由間隙拖動窗口，雙擊此處將其最大化，並且隱形 5 pt 邊緣（12 pt 角）可調整窗口大小。關閉執行檔 › 退出，因此首先會詢問未儲存的文件。
- **macOS：** 交通燈位於整合標題列 (`integrated_titlebar`) 上方。
- **縮小視窗** 在任何重疊之前放置選單中的控制項：主題切換（首選項），然後搜尋（編輯 › 搜尋），然後工作區切換器縮小（視窗 › 工作區）。

## 緊湊的工具控制

當兩個欄位仍然超過可用高度時，工具列會捲動其工具行。前景
和背景顏色在這些行下方保持可見，以及 Pro 的快速遮罩和螢幕
模式控制。長選項行水平滾動。兩個滾動條都帶來了新的焦點
控制項進入檢視並保留現有的工具操作和彈出視窗。

離屏回歸裝置在每個區域都使用生產面板、字體和 SVG 載入器。
主題、800×480 和 1280×720 點視口以及 1×、1.5× 和 2× 顯示比例。為保留其
60 個初始/滾動 PNG，同時執行緊湊幾何和交互檢查：

```sh
CRAFT_UI_VISUAL_FIXTURES=/tmp/photocraft-compact cargo test -p photocraft-ui-egui --lib compact_visual_regressions -- --nocapture
```

鍵盤測試透過首選項清除可設定的`window.togglePanels`畫布快捷方式，
然後透過應用程式的快捷調度程式發送正常的 Tab 和 Space 事件。他們鍛鍊身體
使用此非預設綁定進行焦點遍歷和啟動；預設畫布標籤仍然會切換
面板。這些離屏檢查不會建立本機視窗或平台輸入接受。

## 選單

水平和垂直尺標刻度、標籤和指針標記被剪裁到各自的位置
條。它們的交點是一個清晰的原點正方形，包括平移、翻轉視圖時
或旋轉；原點方塊保留其尺標單位上下文選單。

嵌入應用程式的`panels.menu_bar`和`panels.rail`標誌屬於其當前
會議。恢復已儲存的工作區或記住的面板佈局會保留這兩個標誌，包括
當序列化佈局包含它們的值。面板可見性、停靠欄佈局、標籤和時間軸
可見性遵循已儲存的佈局。

Pro 狀態列的文件尺寸讀數遵循首選項 › 單位和尺標 › 尺標，
包括從尺標的上下文選單中進行的變更。它使用物理文件分辨率
單位、雙方各自的百分比範圍以及所選的點大小約定
和異食癖。讀數保留文件的每英吋像素值。

`menu_catalog.rs`儲存Photoshop的選單樹（標準指令名稱、順序、分隔符號、預設快速鍵）。 ID 與引擎或 UI 指令相符的專案是活動的；其他的則在實作之前呈現停用狀態。為新指令提供目錄 ID（例如`image.imageSize`），它們會自動在正確的位置亮起。

選單永遠不會超出視窗：選單列的選單和子選單用箭頭滾動（`menu_nav::level`），而長的右鍵單擊選單（圖層，畫布工具，色版，路徑，文件標籤）將其行包裝在`widgets::menu_scroll`中，因此它們向上移動以適合併僅在高於可見視窗時滾動。

## 目視檢查自動化

使用`ui.click {x,y}`、`ui.move`、`ui.key`和`ui.type`（螢幕點中的合成輸入）開啟選單、彈出視窗和上下文選單，然後使用`ui.screenshot`。

## 字體選單

類型選項列、字元面板、字元/段落樣式編輯器和字形面板
分享一個可搜尋的家庭選擇器。每個可見行都顯示由以下方式渲染的`AaBbCc`範例
該系列中的PhotoCraft文字引擎（指令碼/符號字體使用它們支援的字元）。一個家族的臉孔也包含阿拉伯語（alef、lam、meem、ain 和範例字母），其左側顯示一個簡短的`أبجد هوز`範例，由同一引擎從右到左成形；一旦該行被繪製，它的行就會保留額外的寬度，並且僅拉丁語族不會改變。
樣本使用有界快取進行快取，並遵循顯示比例和主題文字顏色。
沒有系統字體的建置會預覽捆綁的字體。
當選單打開時，向上/向下應用上一個/下一個匹配系列並將其滾動到
檢視； Enter 接受選擇並關閉選單。 Escape 關閉它，已經保留
應用的變更（編輯 › 撤銷恢復文字圖層字體變更）。

## 偏好設定

首選項有**應用**、**確定**和**取消**。套用儲存編輯的部分並保留
對話方塊開啟；當值與已儲存的首選項相符時，它將被停用。確定儲存並關閉。
取消僅放棄自上次成功應用程式以來所做的更改。失敗的申請會留下
草案開放供修正。標記為下次啟動的設定仍需要重新啟動。
在 Windows 和 Linux 上，系統標題列顯示「下次啟動時套用」。在其複選框下方，
包括編輯前和應用後。儲存此首選項不會重新啟動應用程式或
改變目前視窗的裝飾；下次啟動時會讀取已儲存的選擇。

## 高 DPI 和 4K 顯示屏

編輯 → 首選項 → 介面 → UI 比例立即套用。自動跟隨操作
系統的顯示比例，包括小數比例，例如 125%、150% 和 175%（在 Linux 上，
Wayland 的分數比例或 X11 的`Xft.dpi`），並在視窗之間移動時更新
監視器。系統以 100% 運作的 4K 顯示器保持在 100% (#1278)。固定選擇（75% 至
300%）設定絕對 UI 比例，例如在未縮放的 4K 顯示器上為 200%。畫布縮放快速鍵
繼續獨立於 UI 縮放控製文件。

在具有分數顯示比例的 Wayland 會話中，介面僅在本機中清晰
Wayland 窗口，其中視窗以顯示器的物理解析度繪製
（`wp_fractional_scale_v1`）。透過 Xwayland，合成器放大了較低解析度的窗口，因此
一切都變得模糊並且看起來比所選比例更大（#1072）。窗戶打開通過
連接筆時的 Xwayland (#639)，具有首選項 › 效能 › Linux 顯示伺服器 =
X11，或用`WAYLAND_DISPLAY=`清除；這些也是進行文件拖放的方法，其中
本地 Wayland 缺乏（#386）。清晰文字或拖放：在這樣的桌面上，它是其中之一
直到winit支援 Wayland 掉落。

介面 → UI 字體大小可獨立於 UI 比例和畫布縮放來變更介面文字。
Tiny、Small（預設）、Medium 和 Large 使用主題原始值的 10/12、1、14/12 和 16/12
字體大小，保留標題、說明文字和數字欄位的相對大小。申請或確定
立即更新文字；這種選擇在發布和主題變化時仍然存在。 CJK 後備
字體使用相同的大小，包括首選項更改後加載的字體。

## 本地化

程式碼中的字串保持英文狀態，並且是預設的查找鍵。`crates/ui-egui/src/i18n`映射它們
在渲染時顯示每種語言一個目錄中的文字（`i18n/<code>.tsv`；格式為
記錄在`ja.tsv`的標題）。命令 ID、用於邏輯的選單路徑、控制色版、
CLI 和 MCP 始終使用英文 ID 和標籤。

提供的語言（`complete_menus`標記一個涵蓋每個選單字串和`tl!`文字的目錄；
測試強制執行它）：

- 英語 (`en`)，源語言。
- 日文（`ja`），完整。
- 簡體中文（`zh-hans`；參見 [`localization-zh-hans.md`](localization-zh-hans.md)），完整。
- 繁體中文（`zh-hant`），完整，台灣使用的字彙；`zh-TW`、`zh-HK`、
`zh-MO`和`zh-Hant-*`區域設定都解析為它。解析器區分兩個中文
  指令碼，因此兩個目錄都不會顯示給另一個指令碼的區域設定。
- 西班牙語 (`es`)，完整。
- 俄語 (`ru`)，完整，有三種複數形式（`one|few|many`，參見`plural_russian`）。
- 韓語 (`ko`)，完整，有複數形式。
- 法文 (`fr`)，完整，有兩種複數形式（0 和 1 使用單數）。
- 捷克語 (`cs`)，完整，有三種複數形式。
- 印尼語 (`id`)，完整，有一個複數形式。

-`tr(lang, s)`純字串；`tr_ctx`當一個英文單字需要不同的翻譯；
`tr_id(lang, command_id, label)`為選單專案（由指令 ID 鍵入，英文標籤為
  後備）；`trn(lang, n, one, other)`表示複數；`fmt`填滿`{name}`佔位符，其中
  譯者可能會重新排序。
- 語言為首選項 › 介面 › 語言（`interface.language`:`auto`或一種語言
  程式碼；`auto`遵循系統區域設置，未知程式碼回退到`auto`）。
- 語言變更無需重新啟動即可套用；首選項預覽所選語言，直到
  應用或確定提交。取消恢復已提交的語言。區域偏好標籤
  透過相同的區域設定匹配器進行解析。請參閱[`localization.md`](localization.md)。
- 新增語言：新增`<code>.tsv`和`i18n::LANGUAGES`中的一行（程式碼、本機名稱、目錄、
  複數規則）。下拉式選單、區域設定比對和目錄測試（格式正確、無重複、
  佔位符和省略號一致，命令 ID 存在）選擇它。每隔一次設定`complete_menus`
  選單字串已翻譯；然後進行測試來強制執行它。具有更多複數形式的語言列出了它們
  全部在`@plural`條目中（俄語：`one|few|many`）；該行的複數規則選擇形式。
- 翻譯是乾淨的：根據普通詞彙中英文文本的含義編寫，
  絕不來自其他產品的在地化資源。

目前已在地化：選單、命令面板、對話方塊和麵板（用`tl!("…")`包裝的文字；
`checkbox`、`slider_row`、`dropdown`等小部件和按鈕會翻譯其標籤
他們自己）。當`tl!`文字、選單字串、混合模式名稱、筆刷部分名稱或產生的
首選項標籤沒有標記為`complete_menus`的語言的條目。未翻譯：狀態列
訊息和錯誤（它們仍然是英語，對於代理也是如此），作為用戶資料的名稱（圖層、樣式、
檔案），使用`format!`組裝但未轉換為`fmt`/`trn`的字串。尚未完成：
面板和對話方塊內從右到左的佈局（外殼鏡像，`direction.rs`），
區域設定感知的數字和日期格式，網路建置上的自動語言偵測（本機
建置讀取`LANG`/`LC_*`、macOS 首選語言和 Windows 使用者區域設定）。

Camera Raw 明確涵蓋了所有十種可用語言，包括韓語和
簡體中文。其上下文`cameraRaw`條目區分音調區域，
色帶名稱和字體粗細 Light。標題使用`{layer}`佔位符；用戶層
名稱和通用 RGB/Lab 色版符號保持不變。折疊 ID 使用英文
來源密鑰，因此切換語言會保留開放部分。混合器標籤包裹在
面板寬度。目錄覆蓋率和實際的 shell 語言切換測試強制執行這些規則。

原生 CJK 字體回退遵循選定的 UI 指令碼，並在切換時重設其快取
語言；網路上的字體交付仍然是單獨的工作。

## 數值欄位中的算術

按一下數值並鍵入表達式，然後按 Enter 或移動焦點以完成。
數位欄位接受`+`、`-`、`*`、`/`、餘數`%`、`^`或`**`的冪、括號、
科學記數法和`pi`/`tau`。例如，`1920/2`給出`960`，`(30+15)*2`
給出`90`。共享值欄位在編輯時即時應用普通數字和算術
完成，保留舍入/整數工作流程。字段限制和整數舍入
仍然適用；無效表達式、除以零和非有限結果將被拒絕。
表達式在本地作為算術計算，而不是作為指令碼計算。
