# GPU堆疊前綴重用

針對 #209 進行設計，特別是不透明度、填滿、混合模式和可見性場景 P2–P5。
當前合成器快取輸入頁面和效果圖，但執行完整的色版列表
在每個損壞的區塊上。該提案添加了可重複使用的低層複合材料，無需更改
混合方程式、顏色轉換或損壞策略。

## 安全邊界

規劃器在完整的根級堆疊單元之後記錄一個檢查點：一個基礎層和所有
層剪裁到它。嵌套組、傳遞組和調整透過
此邊界之前的現有規劃器。只有累積的背景才活在那裡；恢復
將其放入檢查點的槽中足以執行剩餘的傳遞。沒有檢查點
放置在群組、剪輯單元或調整程式內。

Blend If 在 GPU 上運作（#4395），遵循此規則：與色版限制一樣，它只會讀取
其自身單元之前的背景（在整個單元中保留，在其末尾釋放），所以沒有任何內容
否則就住在邊界上。高級混合（自 b0680fd 起主要）返回`Unsupported`
來自 GPU 規劃器並使用 CPU 路徑：它必須不斷回退到 CPU，或保持
檢查點邊界規則 - 進階混合的後續 GPU 實作保留了
無論如何，邊界不變。

## 無效

保留檢查點較低層和文件非層狀態的 COW 快照。
比較完整的圖層結構，包括遮罩、嵌套子級、效果、衍生快取
和像素表面。保守比較所有非圖層文件字段，包括顏色模式，
深度、輪廓、全局光和圖案。這故意接受不必要的無效
（例如選擇或元資料變更）以避免不完整的渲染鍵。
共享`Arc<Tile>`資料保持固定，並且對於未更改的共享圖塊，相等短路；
不存在指紋衝突或相依性命令 ID 或聲明的損壞已完成。

如果較低層發生變化，則選擇該單元之前較早的根檢查點，丟棄快取
塊並渲染一次以填滿它。該檢查點之上的後續編輯將重複使用它。開始
與最後一個根單元之前的邊界。驗證規劃器的起始層，傳遞偏移量
還有根槽：檢查點上方的不透明層可以改變遮蔽修剪。

只允許整個網格塊——與合成器的塊網格對齊的矩形——由
它們的網格位置，以合成器的累積格式表示。部分損壞已送達，而不是
錯過了：損壞矩形映射到它相交的整個區塊，部分矩形是
複製為快取的整個區塊的子矩形，因此筆刷筆畫（每個新的部分矩形
幀）填滿整個區塊，而不是用與精確損壞相關的條目來填滿預算
再也沒有擊中的直腸。較低前綴的變更會使每個區塊無效，包括螢幕外的區塊
那些。
切換文件、關閉快取文件、調整大小、更改紋理限製或遺失
裝置釋放快取或使快取失效。快照比較涵蓋了撤消/重做。

## 記憶與提交

每個合成器保留一個前綴，並具有一組有界的塊紋理。將其限制為 512 MiB 並且
從`set_memory_budget`的現有效果/快取部分保留其配額；不減少
現有的層頁限額或默默地超過設定的總數。停止接納新人
塊滿時，因此重複的全畫布刷新不能驅逐自己的下一次點擊。預算變化
立即修剪快取。沒有有用邊界的微小預算和文件可以正常渲染。

將儲存的區塊複製到其累加器槽中，執行後綴，並將最終的根發送到
現有的顯示接收器。當最後一個前綴傳遞完成時捕獲檢查點。無回讀
或引入較低精度的儲存。公開重複使用區塊和跳過的計數器以及
保存用於測試和測量的位元組計數。

只有`render`擁有提交並可以建立重複使用。`encode`採用呼叫者擁有的編碼器，
可以在不提交的情況下刪除：它既不能讀取也不能填滿前綴檢查點。
渲染失敗時丟棄前綴狀態；設備健康檢查仍然控制所有 GPU 工作。

## 驗證和交付

在實施之前，請單獨發布此設計以供審核。實施是有重點的
跟進並引用本文件。保留所有現有的公共渲染結果和 CPU 回退
語義完整。將熱快取輸出與未快取的 GPU 路徑和 CPU Oracle 進行比較，網址為
8/16/32 位元深度和模擬小紋理限制。覆蓋頂部/中間/底部編輯、屬性
更改、剪裁、傳遞和隔離組、調整、遮罩、效果、全域輸入、
遮蔽、結構變化、類似撤銷的快照、不相交的部分損壞、預算縮減/零、
文件替換和廢棄的編碼器。執行現有的 GPU 奇偶校驗和真實檔案語料庫。

測量密集的 24-36 MP 堆疊、冷填滿和重複屬性編輯上的發布渲染，
在同一個二進位檔案中啟用和停用重複使用。之前也執行現有的 P2–P5 場景
以及之後；他們的樣式固定裝置編輯低層，因此只有該單元下面的層可以重複使用。
報告計時、實際跳過的工作和快取位元組。這不能保證 10-20 毫秒的預算：
更改之上的所有層仍然混合，並且全畫布輸出編碼/mips 仍然執行。保留
發布基線，直到有代表性的全面測量證明更改它們是合理的。
