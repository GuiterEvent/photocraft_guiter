PhotoCraft的直接操作與Photoshop2026 (27.11.0) 相比如何：工具箱、
每個手勢的手把和修飾鍵、輕推、捕捉、數位精確度、導航、
快捷方式和麵板。畫作感覺在[`brush-parity.md`](brush-parity.md)中有自己的清單
並在[`context-menu-parity.md`](context-menu-parity.md)中右鍵選單。設計系統
（主題、令牌、小部件）是 [`ui-design.md`](ui-design.md)。

狀態：**完成**（與Photoshop中的行為相同，經過測試），**部分**（存在、不同或未經測試），
**失蹤**。證據是`crates/ui-egui/src/`下的文件，除非給予另一個路徑，
記分卡 ID，或問題。修飾符名稱首先是 macOS (⌘ ⌥ ⇧)； Windows/Linux 使用 Ctrl 和 Alt。

**摘要（估計，權重 = 使用手勢的頻率）：** ~40% 準備就緒。工具 56/68
存在（82%，測量）。自由變換修改器和裁剪接近Photoshop；差距是
在修改器、變換 UI、彈簧加載工具、面板和首選項的長尾。
剩餘時間：變換與修改器 60–110 小時（間隙 G5）、工具 (G6) 60–100 小時、150–250 小時
用於面板和工作區 (G9)。
