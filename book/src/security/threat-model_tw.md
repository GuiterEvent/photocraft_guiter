# 威脅模型

此威脅模型涵蓋來源儲存庫的桌面、CLI、WebAssembly、格式和自動化介面。它假設檔案、路徑、JSON、MCP 訊息、代理決策和嵌入元資料可能是惡意的。

## 資產

- 使用者文件、元資料、憑證和不相關本地文件的機密性；
- 文件、首選項、檔案系統內容和應用程式狀態的完整性；
-PhotoCraft和主機系統的可用性；
- 發佈工件和相依性的完整性和來源；
- 可預測的命令執行和文件保真度。

## 威脅行為者

- 惡意影像、PSD/PSB、`.pcraft`、設定檔、LUT、圖案或嵌入物件的作者；
- 連接到環回伺服器的惡意或受損本地處理程序；
- 惡意、受損或權限過高的 MCP 用戶端或自動化代理；
- 導致不安全路徑或昂貴命令的專案/操作文件；
- 受損的相依性或建置/發佈環境。

## 入口點

```text
untrusted files and bytes
  PSD / PSB / raster / .pcraft / ICC / LUT / pattern / embedded content

untrusted control data
  CLI arguments / filesystem paths / JSON-lines / MCP requests / agent commands

untrusted build inputs
  dependencies / CI actions / release secrets / packaging tools
```

## 主要威脅場景

### 惡意文件解析

緊湊檔案聲明過大的尺寸、過多的色版、嵌套描述符、損壞的偏移量或高度擴展的壓縮資料。期望的結果：在不合理的分配或工作之前拒絕它，返回錯誤，並保留最小化的回歸測試。

### 檔案系統權限濫用

自動化用戶端提供絕對路徑、遍歷序列、符號連結、連接或替換路徑來讀取或覆寫預期專案以外的資料。遠端檔案系統方法使用單獨設定的目錄功能，並且仍然需要環境路徑的引擎命令在自動化邊界處失敗關閉。這還不是通用的每命令功能模型，可信任桌面操作仍然可以使用環境路徑。

### 本地控制權接管

同一台主機上的另一個程序連接到環回控制伺服器、發現方法、驅動 UI 輸入、執行命令或開啟/儲存檔案。在方法分派之前需要 256 位元承載令牌，但驗證不會授予每個用戶端或每個工具的功能。

### 資源耗盡

用戶端打開許多 TCP 連線、發送極長的 JSON 行、建立大量批次、請求全尺寸渲染或重複呼叫昂貴的命令。請求行、連接、批次和預覽限制緩解了某些情況；明確的 JSON 深度、文件記憶體和命令持續時間預算仍然不存在。

### 供應鏈妥協

易受攻擊或惡意的套件、操作、安裝程式工具或簽章環境會變更建置行為或工件。鎖定檔案和發布校驗和有助於重現性和驗證，但諮詢/許可策略檢查和 SBOM 輸出是未來的工作。

## 安全目標

- 盡可能在分配之前拒絕格式錯誤和過大的資料；
- 在解析器/命令邊界使用檢查算術和有界遞歸；
- 使自動化權限明確、狹窄且可撤銷；
- 儘管存在遍歷和連結技巧，但仍將文件存取保留在授權根內；
- 每個請求和每個會話的綁定工作；
- 保留足夠的非秘密審計資料以調查自動化操作；
- 將每個已修復的安全錯誤轉變為永久的回歸測試。

## 非目標和限制

PhotoCraft目前不是用於惡意自動化或惡意本機程式碼的沙箱。環回傳輸、Rust 記憶體安全性、類型化模式和檔案格式檢查不會取代身份驗證、授權、作業系統隔離或操作最小權限。本文件並未聲稱存在那些缺少的控制項。
