# 筆刷與繪畫的奇偶校驗

> **最後審查：** 2026-10-10 · **最後更新：** 2026-10-14 · **更改：** 次要（拖曳預設筆尖預覽；色相抖動量軌道；筆刷設定最小欄位遵循其控制；僅複選框行和非破壞性平滑估計開關筆；筆尖感覺筆觸筆形狀Photoshop2026

繪畫是Photoshop用戶首先註意到差異的地方，因此它有自己的清單：
筆刷引擎（`crates/paint/src/brush.rs`），筆刷設定UI
(`crates/ui-egui/src/brush_sections.rs`)，即時筆畫渲染器，筆輸入
([`hardware-parity.md`](hardware-parity.md)) 和基於筆刷的工具。狀態詞如
[`ui-parity.md`](ui-parity.md).

**摘要（估計）：** 寬度 ~90%（每個筆刷設定部分和選項都存在），準備好
實際工作~55%。引擎型號為Photoshop型號；感覺到的差距（延遲、壓力
響應、邊緣品質、平滑）、一些缺少的選項以及修飾工具的即時預覽。
剩餘時間：100–180 小時（[`gaps.md`](gaps.md) 中的間隙 G4）。人類：感覺必須以真實的方式進行檢查
與Photoshop並排的平板電腦。
