# 簡體中文目錄

`zh-hans`目錄在共享 i18n 基金會中註冊為 **簡體中文**
由 [PhotoCraftPR #169](https://github.com/storytold/photocraft/pull/169) 介紹。
簡體中文支援登陸
[PR #282](https://github.com/storytold/photocraft/pull/282)，v0.2.0 發布後。
此版本不包含語言選擇器或此目錄；使用構建
其中包括本地化更改。

中文措詞原創，使用普通圖像編輯術語；
沒有提取或複製專有翻譯資源。貢獻
使用儲存庫的 MIT 或 Apache-2.0 許可證。

## 選擇簡體中文

選擇**首選項 > 介面 > 語言 > 簡體中文**，或設定
透過現有的`prefs.set`指令將`interface.language`轉換為`zh-hans`。
本機構建的 **自動** 設定為`LANG`/`LC_*`，macOS 首選
語言和 Windows 使用者區域設定。`zh`、`zh-CN`、`zh-SG`和`zh-Hans`
變體解析到此目錄。繁體中文語言環境（`zh-TW`、`zh-HK`、
`zh-MO`、`zh-Hant`）解析為單獨的`zh-hant`目錄。

Web 建置不會自動偵測瀏覽器語言；選擇
那裡手動語言。

## 文件和集成

-`crates/ui-egui/src/i18n/zh-hans.tsv`包含翻譯，獨立於
  尋找實作。其 UTF-8 欄位是`context<TAB>source<TAB>translation`。
-`crates/ui-egui/src/i18n/mod.rs`以複數形式註冊`zh-hans`並
`complete_menus: true`。共享測試強制覆蓋每個選單字串，
`tl!`文字、混合模式、筆刷部分和產生的首選項標籤。
- 快捷方式範本保留`{key}`，以便外殼提供正確的金鑰
  當前平台。層數訊息使用一種中文複數形式。

保持英文來源密鑰、上下文、命令 ID、佔位符和轉義符完好無損。
保留開啟對話方塊的指令的尾部`…`。缺少翻譯使用
框架的英語後備。使用者提供的名稱和文件資料不
翻譯的。產品名稱及技術名稱如PhotoCraft、ArtCraft、
OpenType、RGB、CMYK 和 Lab 保留其拼字。狀態訊息、錯誤和
自動化輸出保持英文，如[UI設計](ui-design.md#localisation)所述；
完整的目錄覆蓋並不聲稱這些字串已被翻譯。

## 驗證和維護

執行`cargo test -pphotocraft-ui-egui`，touched-crate 全目標 Clippy 檢查，
`cargo xtask layers`和`cargo xtask wasm`。共享目錄測試驗證
重複鍵、佔位符、省略號、選單覆蓋、`tl!`文字、筆刷
部分和混合模式。針對中文的測試涵蓋區域設定選擇、後備、
複數訊息、格式化標籤和筆刷部分行和標題。渲染並檢查選單、首選項和代表
與現有的螢幕外`snapshot`範例的對話方塊。

字體傳送與翻譯資料是分開的。目錄不添加字體
資產； shell 的 CJK 後備會單獨載入字體。驗證缺失的字形，
在每個目標平台上直觀地顯示標籤佈局和特定於平台的快捷方式，
並分別驗證網頁字形覆蓋範圍。

當英文標籤改變時，一起更新它們的來源金鑰和翻譯，
保留上下文和占位符。完整目錄測試發現缺失
鍵，簡體中文回歸測試檢查動態快速標籤，
層數和英語後備。對照變更的來源意義進行審查
目前的英文使用者介面。
